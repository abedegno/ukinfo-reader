Back up or move your archive

Export research lists as JSON to back up saved records and notes. Keep copies of your original media and ONSPD ZIP so you can rebuild the searchable catalogue.

For a complete local backup, quit the app and wait for its database to stop before copying the entire app data directory. Restore into a separate directory with the same app version, operating system and CPU architecture. Never copy a running PostgreSQL directory.

Removing an edition preserves research snapshots and notes. Saved source links are unavailable while that edition is absent. Reimporting the same verified edition may make them available again.
