# v14 hosted import and acceptance plan

User authorized all four proposed steps: resolve CO1, private NAS import, six-edition indexing/benchmarks, then publication after acceptance. Keep operational configuration in homelab.

## Decisions and bounds

- The original field constructor names postcode control bit 0x40 CO1; the disc's own help describes CO1 removal requests. Full Windows UI filtering is not asserted from a field-decoder comparison. Hosted selection explicitly excludes all residential occurrences whose source_co1 is true; local archival reading remains lossless.
- Complete audit: 29,410 flagged physical records supply 54,869 occurrences (40,694 electoral, 14,175 telephone). Hosted v14 count: 43,744,633 (26,922,737 electoral; 10,729,888 telephone; 6,092,008 business). Expected six-edition public total: 292,695,740.
- Use dataset key v14-2008-03:co1-excluded and preserve source edition/fingerprints, selection metadata and a fresh terminal digest. Fail closed on missing/invalid selection fields, unknown listing types or count mismatches.
- Preserve the existing five-edition public total and hidden 2003 rollback edition. A restrictive source-dataset policy hides v14 during import; only an internal SELECT-only verifier role can see it. Retain an explicit policy against unselected v14 keys after publication.
- NAS preflight: existing source/derived DBs and APIs healthy; about 22 TiB free, 32 GiB host memory. Build code-only images on NAS with at most 2 CPU/2 GiB. Transfer only the fifteen verified source components; no ISO, local image tar, full JSONL or database copy.
- Keep all real queries, records, coordinates, source IDs and response hashes on NAS. Only aggregate reports return to Mac/repositories. Use internal HTTP for real checks and public HTTP only for inventory/health/UI/invented input.
- Preserve source/target processes, volumes, existing partitions, original backup policy, deadlines and quotas. Hold the shared regression/operator lock across maintenance. Do not merge homelab changes while its exact-head checks are blocked by billing.
